# 个人作品集展示网站 · 需求文档

> 版本：v1.0 · 面向纯前端实现 · 无后端逻辑

## 1. 项目概述

一个**纯前端**的个人作品集展示网站，用于集中展示个人的影视、AI 及其他类型作品与项目。整体采用**商务科技风 / 碳黑金**视觉基调，支持 PC、平板、手机三端自适应，并内置一套**可视化修改工坊**，让使用者无需改代码即可编辑文字、图片、视频、链接等内容，实时预览、保存、还原，最终**打包为静态目录/zip** 直接部署。

## 2. 目标与范围

### 2.1 目标
- 提供专业、有质感的个人品牌展示站点。
- 让非技术用户也能通过可视化界面维护内容。
- 一次编辑，多端适配，一键打包部署。

### 2.2 范围
- **包含**：站点前台展示、可视化修改工坊、模板系统、粒子动效、响应式适配、本地持久化、打包导出。
- **不包含**：任何后端接口、数据库、用户登录、在线协作、SEO 深度优化、第三方支付/统计。

## 3. 用户与使用场景

| 角色 | 场景 |
|------|------|
| 站点访客 | 在 PC / 平板 / 手机上浏览首页、作品集、项目、关于我、技能栈、联系我 |
| 站点所有者（本人） | 打开本地或部署的工坊页面，可视化修改内容并实时查看效果 |

## 4. 页面与功能需求

### 4.1 全局要求
- 导航：**多页导航**（顶部导航栏，PC/平板为横排菜单，手机折叠为汉堡菜单）。
- 三端响应式：随屏宽自动切换布局，无手动切换按钮。
- 粒子动效作为全局背景层，密度随屏宽自适应。
- 页面切换带过渡动画；图片懒加载、回到顶部、骨架屏等体验细节。

### 4.2 首页（Hero）
- 大标题、副标题、一句个人定位 Slogan。
- 可配置背景视频（含封面图 poster）或背景图。
- 核心 CTA 按钮（前往作品集 / 联系我）。
- 滚动入场动画。

### 4.3 作品集页（作品）
- 布局：**响应式卡片网格**（列数随屏宽自适应）。
- 单个作品卡片支持：封面图/视频、标题、描述、标签、链接按钮。
- 可选分类筛选（全部 / 影视 / AI / 产品等）。
- 支持视频播放/暂停、封面图兜底。

### 4.4 项目展示页（项目）
- 布局：**卡片网格**（与作品集视觉统一，标记为可调整为时间线/列表）。
- 内容：项目名称、简介、技术标签、时间、外链。

### 4.5 关于我（本人介绍）
- 重点：**简介 + 技能**。
- 头像、自我介绍文案、技能标签云、短期目标/定位。

### 4.6 技能栈（自动补全页）
- 技术/能力标签云展示，支持分组（如「影视/设计/AI 工具」）。

### 4.7 联系我（自动补全页）
- 联系方式、邮箱，社交链接（GitHub / 邮箱 / 微信 / 其他）。

### 4.8 可视化修改工坊（核心）
- 入口：独立访问路径（如 `?studio=1` 或 `/studio.html`）。
- **左侧**：可视化编辑面板，所有可改项（文字、图片、视频/链接上传等）以完整表单/控件展示。
- **右侧**：iframe **实时预览**，改动即时反馈。
- **保存逻辑**：保存点写入 localStorage；支持撤销/重做。
- **还原逻辑**：回退到上一保存点，或重置为内置默认模板。
- 数据支持 **JSON 导出/导入** 备份迁移。
- 媒体资源：外链 URL 为主，支持上传本地文件转 base64 覆盖。

### 4.9 内容美化调整
- **图片**：透明度、圆角、覆盖/裁剪方式、滤镜（可选）。
- **文字**：预设字体、字号、颜色、字重、对齐。
- **区块**：背景色、间距、卡片圆角等基础样式微调。

### 4.10 模板系统
- 提供 **≥5 套**外观预设模板（含不同配色/布局风格/粒子风格）。
- 切换方式：**全局一键套用模板 + 支持对单个模块局部微调**。

### 4.11 粒子动效
- 风格（四类，模板可选用/组合）：星点悬浮、粒子连线网络、鼠标交互（吸引/斥力）、矩阵/代码雨。
- 密度**随屏宽自适应**，低端机自动降密度保性能。

### 4.12 保存后打包部署
- 一键「打包」：将当前站点内容 + 所选模板渲染结果导出为**静态目录/zip**，可直接部署到任意静态服务器 / GitHub Pages / OSS/CDN。

## 5. 非功能需求

- **兼容性**：避免使用不兼容的浏览器 API（如 `ctx.roundRect`），保证主流现代浏览器可用。
- **健壮性**：任何脚本/资源异常不得导致白屏，需优雅降级与错误兜底。
- **性能**：粒子动效自适应密度；图片懒加载；首屏资源尽量精简。
- **可维护性**：站点内容与样式分离（内容数据 + 模板主题），便于工坊改内容与换皮肤互不干扰。
- **无后端**：所有逻辑在浏览器端完成。

## 7. 验收标准

- [ ] PC、平板、手机三端布局正确缩放，无横向滚动、无错位。
- [ ] 首页 / 作品集 / 项目 / 关于我 / 技能栈 / 联系我 六页均可访问且导航正常。
- [ ] 工坊左侧可完整编辑文字、图片、视频、链接，右侧实时预览同步。
- [ ] 保存后刷新数据仍在；撤销/重做与还原生效；JSON 导入导出可用。
- [ ] 图片可调透明度/圆角，文字可换预设字体/颜色。
- [ ] 可在 ≥5 套模板间切换，并支持局部微调。
- [ ] 粒子动效多风格可切换，且手机端性能流畅。
- [ ] 一键打包生成静态目录/zip，部署后内容与预览一致。
- [ ] 无白屏；异常场景有兜底提示。
