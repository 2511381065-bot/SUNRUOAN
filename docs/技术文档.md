# 个人作品集展示网站 · 技术文档

> 版本：v1.0 · 纯前端 · 无构建依赖（如改用 Vite 需另行说明，本文按纯原生方案）

## 1. 技术选型

| 项 | 方案 | 说明 |
|----|------|------|
| 结构/样式/逻辑 | 原生 HTML + CSS + JS（ES Modules） | 零依赖，双击即可打开 / 静态部署 |
| 粒子动效 | HTML5 Canvas（自绘，不使用 `ctx.roundRect` 等不兼容 API） | 星点/连线/矩阵/鼠标交互 |
| 数据持久化 | `localStorage` + JSON 导入导出 | 工坊编辑数据 |
| 实时预览 | `<iframe>` 同源预览 | 隔离工坊 UI 与站点 UI |
| 媒体资源 | 外链 URL 为主，本地上传转 `base64` | 预览与导出统一 |
| 打包导出 | 前端序列化站点快照 + 生成静态 zip（`JSZip` 可选，或手写 zip） | 目录结构见 §8 |

## 3. 数据模型（站点内容 Schema）

站点内容为一个**可序列化的 JSON 对象**，是前台渲染与工坊编辑的唯一数据源。

```js
const siteData = {
  meta: { title, lang, version },
  theme: "carbon-gold",       // 当前模板 id
  themeOverrides: {           // 局部微调（覆盖模板变量）
    "--color-accent": "#d4a94e"
  },
  hero: {
    title, subtitle, slogan,
    bgType: "video" | "image",
    bgSrc, bgPoster,          // 视频地址 + 封面
    ctaPrimary: { label, href },
    ctaSecondary: { label, href }
  },
  nav: [ { label, href } ],
  portfolio: {
    layout: "grid",
    filters: [ "全部", "影视", "AI", "产品" ],
    items: [
      {
        id, category, title, desc, tags: [],
        mediaType: "image" | "video",
        mediaSrc, poster,
        link: { label, href },
        style: { opacity: 1, radius: 12, filter: "none" }
      }
    ]
  },
  projects: { layout: "grid", items: [ { id, title, intro, tags, time, link } ] },
  about: { avatar, bio, skills: [ { group, items: [] } ], goal },
  skills: { groups: [ { name, items: [ { label, level } ] } ] },
  contact: { email, socials: [ { label, icon, href } ] },
  pageTransition: { type: "fade" },
  particle: { style: "network", density: "auto" }
};
```

**关键约定**：`theme + themeOverrides` 通过 CSS 变量注入；内容数据不含具体样式，样式统一走模板主题。这样「换模板」与「改内容」互不干扰。

## 4. 架构与渲染流程

```
siteData(JSON)
   │
   ├─→ 前台 render.js ──▶ 注入 CSS 变量 + 生成 DOM ──▶ 站点可视化
   │
   └─→ 工坊 studio.html
         ├─ 左栏 form-builder.js（读 schema 生成表单）
         ├─ 中间 store.js（写内存 + localStorage）
         └─ 右栏 <iframe> 复用 index.html?preview=1（读内存快照渲染）
```

- **前台（index.html）**：无 `?preview` 时读 `localStorage`；渲染纯函数式、可多次调用（便于模板切换/还原后重绘）。
- **工坊（studio.html）**：载入 `siteData` → 左栏表单 → 用户改动 → 触发 `store.update(path, value)` → `history.push()` → 刷新 iframe。
- **预览隔离**：iframe 内用 `postMessage` 或直接共享 `localStorage` 快照键，避免工坊样式污染站点样式。

## 5. 响应式断点

| 设备 | 断点 | 布局策略 |
|------|------|----------|
| 手机 | < 768px | 单列；导航折叠为汉堡；卡片单列 |
| 平板 | 768px – 1024px | 卡片 2 列；导航保持横排 |
| PC | > 1024px | 卡片 3–4 列；完整导航 |

- 使用 CSS Grid / Flex + `clamp()`，避免硬编码像素。
- 粒子密度：`density = auto` 时按 `window.innerWidth` 与 `devicePixelRatio` 计算粒子数量上限，低端自动降级。

## 6. 粒子引擎（Canvas）

- 单一 Canvas 铺满背景（`position:fixed; z-index:-1`），`requestAnimationFrame` 渲染循环。
- 四类风格由配置参数切换：

| 风格 | 实现要点 |
|------|----------|
| 星点悬浮 | 随机漂浮小圆点，透明呼吸 |
| 连线网络 | 邻近粒子间距小于阈值时绘制连线，鼠标作为额外节点 |
| 鼠标交互 | 对鼠标位置产生吸引/斥力，计算向量 |
| 矩阵/代码雨 | 按列下落字符，金色/青色调 |

- **兼容性注意（硬约束）**：不使用 `ctx.roundRect`、`ctx.filter` 等新 API，圆角用 `arc()`/椭圆绘制；所有粒子对象与变量**先初始化再使用**，`try/catch` 兜底，异常时隐藏画布而非白屏。
- 页面后台时暂停（`document.visibilitychange`）以省资源。

## 7. 模板系统（≥5 套）

- 每套模板 = 一个 CSS 变量集 + 一组粒子风格参数 + 可选布局小差异：

| 模板 id | 主题 | 粒子风格 |
|---------|------|----------|
| carbon-gold | 碳黑金（默认商务科技） | 连线网络 |
| deep-blue | 深蓝科技 | 星点悬浮 |
| matrix | 黑绿矩阵/AI | 代码雨 |
| starlight | 星空黑金 | 星点 + 鼠标交互 |
| minimal-light | 浅色商务灰（备选） | 星点悬浮 |

- 模板通过 `templates.js` 定义，切换时整体替换 `:root` 变量并重绘，`themeOverrides` 在其上叠加局部微调。
- 满足「全局一键 + 局部微调」：全局切模板，局部改 `themeOverrides` 中单变量。

## 8. 打包导出流程

1. 收集当前 `siteData`（含 base64 内联媒体）。
2. 生成最终静态资源：`index.html`（内联/引用所需 CSS/JS）+ 所有媒体文件。
3. 若媒体为外链，保留原 URL；若为本地 base64，写入 HTML/独立文件。
4. 使用 `JSZip`（或前端手写 zip）打包为 `portfolio.zip` 下载；同时提供「导出目录」预览。
5. 产物为可独立部署的静态目录，无 `studio.html`（或保留一个可选工坊入口）。

## 9. 存储 / 撤销 / 还原

- **存储键**：`psf_site_data`（栈式历史另存 `psf_site_history`）。
- **history.js**：维护快照栈，`undo/redo` 指针；每次编辑压入新快照。
- **保存**：把当前快照写入 localStorage。
- **还原**：回退到最近保存点，或 `resetToDefault()` 恢复内置默认数据。

## 10. 健壮性与兼容性（硬约束）

- 所有脚本统一 `try/catch`，渲染失败输出可见的错误提示而非白屏。
- 变量全部显式初始化，避免未定义引用（历史教训：`hueShift` 未初始化导致报错）。
- 媒体加载失败显示占位/兜底图；视频无封面时退化为首帧或纯色块。
- 不使用 `ctx.roundRect` 等兼容性差的 API，圆角统一用弧线绘制。
